Invoice tool: admin guide

For Zein, over AnyDesk. Design and reasons: DECISIONS.md in the code (D-023 and D-024 for this set-up).

The tool folder

Staff see only the staff folder (e.g. D:\Invoices, with a desktop shortcut to it): 1. Put invoice scans here\, 2. Excel files ready to upload\ (only these get uploaded), Process Invoices and Staff guide. Update refreshes the last two. Everything else is in Admin only\:

In Admin onlyWhat it isUpdate replaces it?
Admin.batYour menu (below)No
app\The code, from GitHubYes, only this (old copy kept as app.old)
data\Everything learned, the PowerSoft files, reports, backups, this guideNever
processed\Scans after reading (by date)Never
output\Uploaded\<date>\Files staff marked as uploaded on the Done screenNever
logs\error.logEvery error, with full details and timeNever
.envThe Azure endpoint and keyNever

Everything lives on the ThawSpace drive. Anything on C: (including the desktop) is wiped at restart unless Deep Freeze is in thawed mode.

Admin.bat menu

1Review window in admin mode: also the invoices staff sent to you ("I'm not sure"). Extra buttons: Take out (enter by hand) and Start this invoice again.
2Update from GitHub. Downloads the newest code, checks it starts with the real data, and goes back by itself if it doesn't. data\ is never touched.
3Undo the last update (puts app.old back).
4Pack check: which single item each pack item counts as. Optional: the report shows this by itself after a new export.
5Open what the tool has learned (data\supplier_items.xlsx) in Excel, to delete a wrong answer: find the row (filter on Supplier description, or Key = the barcode), delete the whole row, save, close. That line is asked again next time. Close Excel before anyone processes invoices.

When staff message you

  1. "Contact Zein" error: open logs\error.log and read the last entry (bottom of the file).
  2. "Waiting for Zein": run Admin.bat → 1 and answer the question, or take the invoice out to enter by hand.
  3. What happened in a run: data\reports\, newest file. It lists each invoice, what staff confirmed, cost changes, new items, what to upload, skipped and by-hand invoices, and notes about the PowerSoft export.
  4. A fix in the code: Claude pushes it to GitHub, then Admin.bat → 2.
  5. "Not for the shop": lines staff left out (home, the restaurant) are in the report under their invoice, with the amount. The Purchase order total is lower than the paper by exactly those.

PowerSoft item export (about once a month)

The tool's list of items, costs and barcodes. Do it after adding items or packs in PowerSoft by hand, or when the report says the export is old.

  1. In PowerSoft, open the item list export and choose the columns:
    • Main details: tick Supplier, Barcode, VAT, Brand, Category. Untick everything else (Stock is ticked by default: untick it).
    • Prices: keep Price 1, untick Price 2, 3, 4, 5, tick Cost.
    • Others: tick Storable.
    • Nothing else.
  2. Export as CSV. Save it as itemsList.csv (PowerSoft's own name) into
    Admin only\data\powersoft\, replacing the old one.
  3. That's all. The next run keeps a dated copy and uses it. Your next report starts with "New PowerSoft export in use", and lists every pack and the single item it counts as. Check any line marked NEAR NAME or NOT LINKED.
If the export is missing a column or looks cut off (far fewer items than the last one), the tool keeps using the previous export and the report says why. Export again.

Monthly check of what was learned

A wrong staff answer ("Is it this item? YES" on the wrong flavour) is remembered and used from then on without a question. With the new export, also copy Admin only\data\ to your PC and ask Claude to run scripts\check_learned.py on it. It lists answers worth a look (names with different words, a better-fitting item, a cost far from PowerSoft's). Delete the wrong ones at the shop with Admin.bat → 5.

Other PowerSoft files

  • New supplier or category in PowerSoft? Export the list again and replace data\powersoft\suppliers.xlsx or categories.xlsx, with the same file name and the same layout as now. The report warns if a supplier the tool reads has no supplier code.
  • Packs (a non-storable item that takes N singles off stock): name it exactly like the single item plus xN, e.g. KYKKOS WATER 500ML X12. Then export again.
  • data\flag_items.csv: items that always get a question (single/pack pairs that are both storable).

Backups and restoring

  • The first run each day zips everything learned into data\backups\backup <date>.zip (30 days kept).
  • To restore: close the tool, unzip the newest good backup into data\ and overwrite.
  • Now and then, copy the whole data\ folder to your own PC over AnyDesk (protects against a dead disk).
  • If supplier_items.xlsx goes missing, the tool refuses to start ("contact Zein") rather than starting from zero. Restore it from a backup.

Things to remember

  • Azure: the free trial ends around 14 November 2026. Upgrade the subscription to pay-as-you-go before then (the Document Intelligence resource stays on the free F0 tier, 500 pages a month). The key is in .env.
  • Cost updates (open question): check once whether a Purchase order upload changes an item's stored cost. Until then, the Done screen sends files with cost changes through Items import (Modify) too. Tell Claude the answer.
  • Time saved: data\state\timings.csv has lines, questions and minutes per invoice: the real numbers for the CV.
  • Staff never create items by hand in PowerSoft: the tool hands out item codes in order and would clash.

First install / new PC

  1. On the ThawSpace drive, make the staff folder with Admin only inside it, and put setup.ps1 (from app\deploy\ or GitHub), .env and data\ in Admin only. The install zip Claude makes is already laid out like this.
  2. Run in PowerShell (double-clicking is blocked):
    powershell -ExecutionPolicy Bypass -File "D:\Invoices\Admin only\setup.ps1"
  3. Make the desktop shortcut to the staff folder in Deep Freeze thawed mode, or it disappears at restart.
